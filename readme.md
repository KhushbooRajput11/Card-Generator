# 🎴 Card Generator

A simple and interactive Card Generator built using HTML, CSS, and JavaScript.

## ✨ Features
- 🎨 Attractive user interface
- 📝 Dynamic card generation
- ⚡ Interactive functionality
- 🌐 Runs directly in a web browser

## 📸 Project Screenshot

![Card Generator Screenshot](card-generator.png)

## 🛠️ Technologies Used
- **HTML5** – Page structure
- **CSS3** – Styling and layout
- **JavaScript** – Interactivity and functionality

## 📂 Project Structure

```text
Card-Generator/
└── index.html
```

## 🚀 How to Run
1. Download or clone this repository.
2. Open `index.html` in your web browser.
3. Use the card generator.

## 💻 Implementation

The entire project is contained in a single HTML file. It includes:
- HTML for the page structure
- CSS inside a `<style>` tag
- JavaScript inside a `<script>` tag

No separate CSS or JavaScript files are required.
